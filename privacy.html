KPW Proxy Manager 개인정보처리방침

시행일: 2026년 11월 15일

KPW Proxy Manager(이하 "프로그램")는 Korea POV Walk 채널 운영자가 자기 영상 작업에만 쓰는 1인용 Windows 프로그램입니다. 이 방침은 프로그램이 Google 사용자 데이터를 어떻게 다루는지 설명합니다.

1. 접근하는 정보

  • Google 계정 이메일 주소: 올바른 계정에 연결되었는지 사용자에게 보여 주고 확인받는 데에만 씁니다.
  • Google Drive의 폴더·파일 정보(이름, ID, 크기, 체크섬): 운영자 본인의 촬영 프로젝트 폴더를 찾고, '저용량' 폴더를 만들고, 업로드 결과를 확인하는 데 씁니다.
  • 프로그램은 사용자가 직접 변환한 저용량 영상과 대응표 파일만 올립니다. Drive의 기존 파일 내용은 읽지 않고, 기존 파일·폴더를 지우거나 덮어쓰지 않습니다.

2. 저장과 전송

  • Google 인증 정보(토큰)는 사용자 PC의 프로그램 폴더에만 저장됩니다.
  • 프로그램은 Google 외의 어떤 서버로도 데이터를 보내지 않습니다. 운영자나 제3자가 따로 모으는 정보가 없습니다.
  • 광고, 분석 도구, 제3자 공유가 없습니다.

3. Google API 서비스 사용자 데이터 정책 준수

프로그램이 Google API에서 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Google API 서비스 사용자 데이터 정책과 제한적 사용(Limited Use) 요구 사항을 따릅니다.

4. 권한 해제와 데이터 삭제

  • Google 계정 → 보안 → 타사 앱 및 서비스 연결에서 언제든 이 앱의 접근 권한을 해제할 수 있습니다.
  • 프로그램 폴더를 지우면 PC에 저장된 인증 정보도 함께 지워집니다.

5. 변경

이 방침이 바뀌면 이 페이지에 새 시행일과 함께 게시합니다.

Privacy Policy (English)

Effective date: November 15, 2026

KPW Proxy Manager ("the app") is a personal, single-user Windows tool used by the operator of the Korea POV Walk channel for the operator's own video work.

Information accessed

  • Google account email address: shown to the user only to confirm that the correct account is connected.
  • Google Drive folder and file metadata (names, IDs, sizes, checksums): used to find the operator's own project folders, create a proxy subfolder, and verify uploads.
  • The app uploads only proxy videos and manifest files created by the user. It does not read the content of existing Drive files and never deletes or overwrites existing files or folders.

Storage and sharing

  • OAuth tokens are stored only on the user's own PC, in the app folder.
  • The app sends no data to any server other than Google. No data is collected by the operator or by third parties. There are no ads or analytics, and nothing is shared with third parties.

Google API Services User Data Policy

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time in Google Account → Security → Third-party apps & services. Deleting the app folder removes the stored credentials.

Changes

Any changes will be posted on this page with a new effective date.
