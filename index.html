KPW Proxy Manager

Korea POV Walk 채널 운영자가 직접 쓰는 개인용 Windows 프로그램

KPW Proxy Manager는 운영자가 직접 촬영한 4K 도보 영상을 분석용 저용량 MP4로 변환하는 프로그램입니다. 변환한 파일과 원본↔저용량 시간 대응표를 운영자 본인의 Google Drive 촬영 프로젝트 폴더에 올립니다. 일반에 배포하지 않는 1인용 도구입니다.

Google 사용자 데이터 사용

  • Google Drive API(https://www.googleapis.com/auth/drive)를 사용합니다. 운영자 본인의 Drive에서 촬영 프로젝트 폴더를 찾고, 그 안에 '저용량' 폴더를 만들어 변환한 파일을 올리는 데 필요합니다.
  • 업로드가 끝나면 파일 이름·크기·체크섬만 읽어 결과를 확인합니다. 기존 파일·폴더를 지우거나 덮어쓰지 않습니다.
  • 인증 정보는 운영자의 PC에만 저장되며, Google 외의 어떤 서버로도 보내지 않습니다.

개인정보처리방침 (Privacy Policy)

About (English)

KPW Proxy Manager is a personal, single-user Windows tool used by the operator of the Korea POV Walk channel. It converts the operator's own 4K walking videos into small proxy MP4 files and uploads them, together with timecode manifests, to the operator's own Google Drive project folders. It is not distributed to the public.

It uses the Google Drive API (auth/drive scope) only to find the operator's project folders, create a proxy subfolder, upload the converted files, and read file names, sizes and checksums to verify uploads. It never deletes or overwrites existing files. Credentials are stored only on the operator's own PC and are not sent to any server other than Google. See the Privacy Policy.
